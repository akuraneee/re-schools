# re:schools

Приложение для Android к электронному дневнику [schools.by](https://schools.by).

- **Главная**: новые отметки с прошлого захода (кроме сегодняшних), отметки за сегодня и ДЗ на завтра
  (в пятницу — на понедельник).
- **Дневник**: полный дневник по неделям — уроки, ДЗ и отметки, переход по неделям стрелками или свайпом.
- **Расписание**: уроки недели (номер и предмет) из дневника, недели листаются так же. Времени звонков и кабинетов в дневнике нет.
- **Статистика**: средний балл, динамика за 30 дней, распределение отметок и средние по предметам за год / 30 / 7 дней. При первом открытии подгружает недели с начала учебного года.

Вход — на самом сайте schools.by, приложение пароль не видит. Дневник и снимок отметок хранятся только на телефоне.
Без сети показываются сохранённые данные.

## Установка

Откройте на телефоне ссылку
[re-schools-android.apk](https://github.com/akuraneee/re-schools/releases/latest/download/re-schools-android.apk)
и установите файл (разрешите установку из этого источника, если телефон спросит). Затем войдите в schools.by.

## Как это устроено

Нативное приложение: Kotlin + Jetpack Compose, интерфейс в стиле Material 3 Expressive
(Material3 1.5.0-beta02: `MaterialExpressiveTheme`, пружинное движение, `NavigationSuiteScaffold` с `ShortNavigationBar` /
`WideNavigationRail`, гибкие app bar, сегментированные списки, `LoadingIndicator`, волнистый прогресс, формы `MaterialShapes`,
динамические цвета Android 12+ и фирменная схема из Material Theme Builder на остальных).

```
core/    ядро на чистом Kotlin/JVM, без Android: тесты идут без SDK
  Parser.kt     разбор HTML недели дневника и страницы ученика (Jsoup); из schools++ (src/parser.js)
  Diary.kt      загрузка недель, поиск четверти по ссылкам, кэш
  Logic.kt      отметки за сегодня, ДЗ на завтра, новые отметки, «заходы»
  Session.kt    дневник одного ученика + состояние захода; Profile — ученики и настройки
  Text.kt       русские даты, названия предметов, уровни отметок
  src/testFixtures/…/FakeSite.kt   выдуманный schools.by («Тестов Тест», ID 1234567)
app/     приложение: Compose-интерфейс (ui/home, ui/diary, ui/settings, ui/welcome, ui/web, ui/theme),
         AppViewModel, OkHttp-транспорт с куками WebView, файловое хранилище
```

Вход — на настоящей странице schools.by во встроенном WebView; приложение пароль не видит. Куки входа общие
у WebView и OkHttp (`WebViewCookieJar`), поэтому дневник загружается теми же запросами, что и на сайте. После входа сайт
открывает `/pupil/<id>` (или `/parent/<id>`) — приложение узнаёт ученика и грузит дневник.

## Команды

```bash
./gradlew -PcoreOnly :core:test        # тесты ядра на выдуманном сайте, Android SDK не нужен
./gradlew :app:assembleRelease         # APK; нужны JDK 17+ и Android SDK 37
./gradlew :app:testDebugUnitTest       # Robolectric: рендерит экраны в PNG → app/build/screenshots
```

Скриншот-тесты (`app/src/test/…/ScreenshotTest.kt`) собирают выдуманный дневник и рисуют главную, дневник, настройки
и вход в светлой/тёмной теме, на планшете и при шрифте 200%. В CI они не запускаются.

APK собирает GitHub Actions (`.github/workflows/build.yml`) на каждый push; в `main` — ещё и релиз
с файлом `re-schools-android.apk`. Версия — `rs.version` в `gradle.properties` (последнее число в CI — номер сборки).
Постоянный ключ подписи — секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`,
`ANDROID_KEY_PASSWORD` (как в schools++); без них каждая сборка подписана новым временным ключом и не ставится
поверх старой.

## Что не проверено на настоящем сайте

- Куда schools.by переводит после входа. Оболочка ждёт `/pupil/<id>` или `/parent/<id>` на поддомене школы.
- Где стоит ДЗ: по описанию из schools++ — в строке урока, на котором его задали. Тогда ДЗ на завтра берётся
  с предыдущего урока того же предмета (под ним подпись «задано …»). Если окажется наоборот — переключатель
  в настройках «Где schools.by пишет ДЗ».
