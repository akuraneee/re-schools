# re:schools — заметки для Claude

Android-приложение к дневнику schools.by: «Главная» (новые отметки с прошлого захода, отметки за сегодня, ДЗ на завтра)
и «Дневник» (по неделям). Устройство и команды — в README.md. Пользователь общается по-русски; интерфейс, комментарии
и README — на русском.

- Разбор сайта взят из `../schools++` (`src/utils.js`, `src/parser.js`, пространство имён переименовано `SPP` → `RS`).
  Описание ответов schools.by — `../schools++/docs/schools-by.md`. Ловушка: в ответе недели два `.db_days`,
  первый скрыт и с заниженными на 2 отметками — берём видимый.
- `../schools++/samples/` — настоящие страницы с личными данными: не копировать и не цитировать. В тестах только
  выдуманный ученик «Тестов Тест», ID 1234567, `demo.schools.by` (`test/fake-site.js`).
- Сайт schools.by недоступен из окружения Claude. Проверка — `npm test` и `npm run selftest` (Electron на fake-site,
  скриншоты в `RS_SHOT_DIR`; окно offscreen, иначе снимки отстают на шаг).
- Electron: проход запросов к настоящему сайту — `passthrough()` через `net.request` с `redirect: 'manual'`
  (у `net.fetch` ручные редиректы падают, а с автоматическими окно не видит итоговый адрес после входа).
- Android SDK локально нет, `dl.google.com` отдаёт 404 на загрузку SDK из этой сети — APK собирает GitHub Actions.
- «Новый заход» — открытие после перерыва ≥ 15 минут (`RS.VISIT_GAP`); новые отметки сравниваются со снимком конца
  прошлого захода (`RS.snapshot`), недели, впервые загруженные при листании, новыми не считаются.
